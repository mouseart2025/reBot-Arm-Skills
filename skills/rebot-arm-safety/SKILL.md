# reBot Arm 安全使用规范（必读）

## 简介

本技能是**所有真机操作的前置必读**。机械臂是带电机、可快速运动的设备，DM（24V）与 RS（**48V**）都存在电气与机械风险。任何 AI 引导的真机操作，都必须先完成本技能的检查清单，并随时准备断电。

> 🔴 **核心原则**：**失控立即断电**。电源开关要放在手边；任何异常（剧烈抖动、撞限位、异响、冒烟、跌落）第一步都是断电，而不是去"按停程序"。

## 何时使用

- 任何涉及机械臂供电、接线、使能电机、运动控制、数据采集、推理的任务开始前
- 用户第一次上手、环境不熟悉、或出现任何异常状况时
- AI 助手在给出运动类指令（遥操作、move、训练推理、轨迹）之前

## 1. 电气安全

| 项目 | DM（24V） | RS（48V） |
|------|-----------|-----------|
| 额定供电 | 24V（官方 24V 14.6A MeanWell） | **48V**（官方 48V 12.5A MeanWell） |
| 风险等级 | 较低（仍按规范操作） | **更高：48V 属高压，接线/带电操作风险显著提升** |

**强制规则**：

1. **断电操作**：插拔任何电机线（XT30/XT60/信号线）前**必须断电**，禁止热插拔（带电插拔会导致电机参数异常甚至损坏）。
2. **电源选择**：只使用正规品牌电源（官方开源 MeanWell 电源或同规格正规电源）。**禁止**无品牌劣质电源。
3. **电压档位**：电源侧面的电压选择开关按市电设置——家用电 220V 拨到 **230V**，110V 拨到 **115V**；上电前必须确认。
4. **反接防护**：正负极接反会损坏电机与控制器；接线前核对 XT30/XT30 接口方向，**上电前再检查一遍**。
5. **接地**：电源与电脑按规范接地，避免静电/漏电损伤设备。
6. **堵转与过热**：不要让关节在限位处长时间堵转（电机堵转电流大、过热），出现堵转立即断电降温。
7. **环境**：避免潮湿、高温、粉尘环境；线束固定好，避免运动中被绞入。

## 2. 机械安全

1. **夹伤风险**：夹爪闭合力大，**手指不要伸入夹爪开口**；调试夹爪时保持手远离。
2. **碰撞风险**：运动范围内清除人员与障碍物；保持 **≥1 m** 安全距离观察。
3. **坠落风险（重点）**：
   - RS（QDD 低减速比）断电后关节**自锁性弱，手臂可能直接砸下**——断电/失能瞬间必须扶稳机械臂或让它处于安全姿态；
   - DM（高减速比）有较好自锁性，但高速运动或超载下同样可能坠落。
4. **急停**：运行前确认**电源开关位置与断电方式**（硬件急停 = 切断电源）；软件层使用 `disable` 服务/`Ctrl+C` 前的安全回零（见对应技能），但**硬件断电永远是最可靠的急停**。
5. **负载红线**：额定负载内运行；**最大负载是物理红线**，超载运行可能导致关节断裂、结构坍塌。
6. **固定**：机械臂底座用夹具/螺丝固定牢靠，桌面承重足够，周围留出安全距离。

## 3. 人机协作与环境

- 操作时**他人保持安全距离**，不要在旁人手臂/面部附近运动机械臂。
- 工作区整洁：移除易碎、尖锐、贵重物品；物体放置在可达范围内。
- 建议佩戴护目镜（防止夹爪弹射小物体）。
- 儿童必须在成人监护下操作。

## 4. 检查清单（AI 引导操作前逐项确认）

### 4.1 首次上电前

- [ ] 已确认电源电压档位正确（230V/115V）
- [ ] 电源、机械臂、电脑接线牢固，正负极方向正确
- [ ] 所有 XT30/XT60/信号线已插紧，无裸露导体
- [ ] 机械臂固定在稳定桌面/支架上
- [ ] 机械臂周围 50 cm 内无人员与障碍物（调试时保持 1 m）
- [ ] 关节处于安全姿态（零位或接近零位），无外力压在手臂上
- [ ] 手边有电源开关，随时可断电
- [ ] 已确认型号（DM 串口 / RS CAN）与对应接线

### 4.2 每次运行前

- [ ] 机械臂周围无人、无障碍物
- [ ] 电源接触良好（遥操作/运动中途电源脱落=危险，须先停程序再重新上电）
- [ ] 夹爪无夹持物残留、手指远离夹爪
- [ ] 程序参数合理（速度、力矩、限位），先低速验证
- [ ] 新任务第一次运行：**有人值守，手在电源开关旁**，先空载低速试跑

### 4.3 紧急情况处理流程（失控/异常）

```
发现异常（剧烈抖动 / 撞限位 / 异响 / 冒烟 / 跌落）
        │
        ▼
1. 立即断电（拔电源或按电源开关）  ← 第一步永远是断电
        │
        ▼
2. 扶稳/固定机械臂，防止坠落伤人
        │
        ▼
3. 检查关节状态与外观（有无损坏、发热、堵转）
        │
        ▼
4. 排查原因（程序参数？接线？负载？姿态？）
        │
        ▼
5. 恢复：低速、小范围重试验证，确认正常后再继续
```

### 4.4 异常断电原则（来自官方教程）

1. **异常抖动** → 立即断电（高频正反力矩会损坏电机）
2. **撞击限位** → 立即断电（电机可能堵转，过热损坏）
3. **突发摔落等异常** → 立即断电，防止二次伤害

## 5. 遥操作/运动场景的特殊安全规则

- 遥操作中主从臂**电源脱落、接触不良、信号线脱落**：必须先停止代码 → 机械臂回到初始 0 点 → 重新上电 → 再运行程序（防止数据错乱导致失控）。
- 遥操作首次运行必须有人值守；先慢速验证映射方向与范围，再提速。
- 数据采集/推理结束时**用 ESC 而非 Ctrl+C**（见对应技能），让机械臂完成安全收尾；停之前先把机械臂移回安全位，避免停在半空受力姿态。
- 自动运行（推理/视觉抓取）前**必须先空载验证轨迹**。

## 6. AI 助手行为守则

1. **先安全后操作**：引导任何真机操作前，先加载本技能并带领用户完成 4.2 检查清单。
2. **型号确认**：先确认 DM/RS（电气参数与断电风险不同）。
3. **不跳过步骤**：用户催促时也不省略安全检查与断电预案。
4. **异常即断电**：用户报告任何异常，第一指令永远是"断电"，而不是继续调试。
5. **如实说明**：不确定的操作明确告知用户以官方文档为准，必要时建议联系官方支持（[Seeed Wiki](https://wiki.seeedstudio.com/)）。
